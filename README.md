# focus-timer-extension
集中時間と休憩時間を効率的に管理するためのChrome拡張機能

# 開発背景
課題やテスト勉強の際に、ポモドーロ機能を持ったタイマーアプリ(スマホ版)をよく使っていた。パソコンでもその機能を使えないかと考えて作成した。
パソコンではブラウザを起動して作業することが多かったため、ブラウザ(chrome)を開いて同時に起動して使えるようにchromeの拡張機能として開発した。

# 特徴
- 通常の拡張機能のポップアップでは画面操作の邪魔になり使いにくかったため、別ウィンドウで開けるようにして画面上の好きな場所に配置できる機能を実装しなおした。
- ポモドーロは集中時間25分、休憩時間5分と固定されているものもあるが、自分が使いやすいように集中時間は自分で設定できるようにして、休憩時間はダラダラしすぎないためにも5分と固定した。

# 使用技術
- JavaScript
- HTML5 / CSS3
- Chrome Extension API
